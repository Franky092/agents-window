# agents-window

A Claude Code mod that adds a pane with live cards for the agents running in your session. Each card shows the agent's name, type, task, status and a timer, with a coloured border per status. Running agents sort to the top, and finished ones stay visible for a minute. Open the pane again with the `/agents` command.

## Install

At the prompt of a terminal session:

```
/plugin install agents-window --marketplace Franky092/agents-window
```

From a shell:

```
claude plugin install agents-window --marketplace Franky092/agents-window
```

Answer `y` to add the marketplace, then pick a scope. The repository is private, so GitHub must be set up on your computer.
